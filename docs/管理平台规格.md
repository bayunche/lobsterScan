# OpenClaw 管理平台规格

> 配套：`docs/开发文档.md` §7
> 命名：内部叫"管台"；面向开发 / 运营 / 比赛评委演示集群运转

## 一、目标用户与边界

- **目标用户**：项目工程师、运营、评委
- **不做**：终端用户的汇报材料生成（那是"会汇报"）
- **必做**：让一个新人 ≤30 分钟把 8 个 Agent + Skill + Channel 都看清楚、改清楚、监控清楚

## 二、信息架构 (Sitemap)

> 该平台是**控制面（control plane）**：所有 OpenClaw、Agent、Skill、Provider、Secret、视频通道、Token 计费的统一入口。业务后端是**数据面**，向控制面上报指标。

```
/admin
├── /dashboard            集群概览（Gateway / Agent / Token / Storage 四块入口卡）
├── /health               Gateway / CLI / Agent 心跳
│
├── /agents               Agent 列表（8 大 Agent + 状态点）
│   └── /[id]             查看 SOUL.md / AGENTS.md / USER.md（V0 只读，V1 开写入下发）
├── /skills               Skill 市场（按分类：内容生成 / 视觉 / 视频 / 检索 / 质量）
├── /bindings             Channel 绑定可视化（读 openclaw.json）
├── /sessions             会话浏览（读 ~/.openclaw/agents/<id>/sessions/*.jsonl）
│
├── /pipelines            流水线列表（TaskRun，含 8 步 Gantt 条）
│   └── /[taskId]         任一 task 的步骤明细表
├── /tokens               Token 计费（按 Agent / 总量 / 成本）
├── /storage              data/outputs · data/uploads 浏览 + 清理
│
├── /config               Provider/TTS/视频参数 + 一键下发到所有 Agent
├── /secrets              API Key 集中管理（Fernet 对称加密）
├── /avatars              数字人形象库（HeyGen AVATAR / 自托管头像）
└── /audit                平台所有写操作审计
```

V0（当前已交付）：12 页面壳 + 后端 13 个路由组 + SQLite 持久化 + Fernet Secrets + Audit Log + Pipelines Seed。
V1（接入 OpenClaw 后）：SOUL/AGENTS 写入 + 真 reload 触发；流水线接业务后端；Token 上报真接入；Skill 批量挂载。

## 三、关键页面 UI 草图

### 3.1 `/admin/agents`

- 8 张 Agent 卡片（grid 3×3，第 9 格放"新建 Agent"）
- 每张卡片：
  - 顶部：状态点（绿/黄/红）+ Agent 中文名 + ID（小字灰色）
  - 中部：当前 Provider/Model、挂载 Skill 数量、最近一次任务时间、近 24h 成功率
  - 底部：3 个 quick action — `编辑` / `查看会话` / `调试`

### 3.2 `/admin/agents/[id]`

- Header：状态、ID、当前模型；右侧按钮 `保存` / `重载`
- Tabs：
  - **SOUL.md** — Monaco Editor，左 YAML frontmatter，右正文；保存时校验 `name`/`description`/`version`
  - **AGENTS.md** — 同上，附加 "Skill 列表" 子区
  - **USER.md** — 同上
  - **Skills** — 当前挂载的 Skill 列表 + 卸载按钮 + "去市场挂载"
  - **Sessions** — 最近 20 个 session，行点击进 `/admin/sessions/[id]`
  - **Errors** — 最近 50 条错误（含原始 error_code，业务化文案）

### 3.3 `/admin/skills`

- 顶部筛选：分类 `内容生成 / 视觉 / 视频 / 检索 / 质量`、来源 `garden-skills / humanizer / heygen / video-toolkit / custom`、已安装与否
- 卡片：Skill 名 / 一句话用途 / 版本 / 已挂载到哪些 Agent
- 详情抽屉：SKILL.md 预览（语法高亮）+ "挂载到…" 多选 Agent + 版本切换

### 3.4 `/admin/pipelines/[taskId]`

- 顶部：任务标题、汇报类型、状态、总耗时
- 中部：Gantt 横道图（按 9 个 step）+ 颜色：成功/重试/失败/跳过
- 点击某 step：右侧抽屉显示 input/output JSON、耗时、Agent 日志（脱敏）
- 底部按钮：`查看产物`（拉所有 artifacts）、`一键重放此 step`（V1.0）

### 3.5 `/admin/health`

- 上：Gateway 状态 + 最近 1h QPS / 失败率折线（mini）
- 中：8 个 Agent 状态点阵 + 各自心跳延迟
- 下：Provider 配额（Claude tokens 余量、HeyGen 视频额度）

## 四、后端职责（不经过 Gateway）

- 直接读写 `~/.openclaw/openclaw.json` 与 `~/.openclaw/workspaces/<id>/*.md`
- 写 SOUL/AGENTS/USER 前：
  - 校验 YAML frontmatter（必填字段）
  - 备份原文到 `.backups/<id>/<file>_<ts>.md`
- Skill 安装：
  - 解析来源（git url / 本地路径 / .zip）
  - 释放到 `cache/skills/<name>@<ver>/`
  - 校验 SKILL.md
  - 复制/软链到 `workspaces/<targetAgent>/.agents/skills/<name>/`
  - 调用 `system.reload-skills` 让目标 Agent 立刻加载
- 流水线监控：消费业务后端写的 `TaskRun` 表（`tasks.db` / Postgres）
- 健康检查：执行 `openclaw agents list` / `openclaw channels status --probe`，缓存 5s

## 五、API（详见 `docs/API接口规范.md`）

| Method | Path | 说明 |
| --- | --- | --- |
| GET | `/admin/api/agents` | 列出 |
| GET | `/admin/api/agents/{id}` | 详情含 skill list / health |
| GET | `/admin/api/agents/{id}/files/{which}` | which ∈ soul/agents/user |
| PUT | `/admin/api/agents/{id}/files/{which}` | 写入 + 备份 + reload |
| POST | `/admin/api/agents/{id}/actions/reload` | 显式重载 |
| GET | `/admin/api/skills/catalog` | 市场 |
| GET | `/admin/api/skills/{name}` | 详情 + README + SKILL.md |
| POST | `/admin/api/skills/install` | `{ name, version, target_agents[] }` |
| DELETE | `/admin/api/skills/{name}` | `?target_agent=<id>` |
| GET | `/admin/api/bindings` | 当前 |
| PUT | `/admin/api/bindings` | 写入 + reload gateway |
| GET | `/admin/api/sessions?agent_id=&limit=` | 列 |
| GET | `/admin/api/sessions/{id}/messages` | 时间线（脱敏） |
| GET | `/admin/api/pipelines?status=&limit=` | TaskRun 列表 |
| GET | `/admin/api/pipelines/{taskId}` | step 详情 |
| GET | `/admin/api/health` | 聚合心跳 |
| GET | `/admin/api/config` / PUT | Provider / TTS 切换 |
| GET | `/admin/api/templates/{kind}` / PUT | report / html-themes / avatars |

## 六、安全

- MVP：本地访问 + Basic Auth（`.env.admin` 给一组用户名密码）
- V1.0：SSO / RBAC（admin / readonly）
- 所有写操作记审计日志 `data/admin-audit.log`（who, when, what, before/after diff）

## 七、可演示性

比赛 Demo 走管台路径：
1. 打开 `/admin/agents` 展示 8 卡片（领导一眼看到"集群"）
2. 进 `html-designer` 详情 → 展示挂载的 `web-design-engineer` / `web-video-presentation` / `gpt-image-2`
3. 切到 `/admin/pipelines/[taskId]` → 让 Gantt 图实时跑 9 步
4. 跳到业务前端看输出
5. 回 `/admin/health` 展示集群整体状态
